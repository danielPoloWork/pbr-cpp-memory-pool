# Session journal

Dated, end-of-session **checkpoints** — what got done, where the project stands,
and how to resume — one file per session under `YYYY/MM/`. These were extracted
from `ROADMAP.md` so the roadmap stays a forward-looking plan rather than also
carrying an ever-growing log ([ADR-0036](../adr/0036-session-journal-extraction.md)).
`ROADMAP.md` links to the latest entry; the full trail lives here, newest first.

> How to add one: at the close of a work session, create
> `docs/journal/<YYYY>/<MM>/<YYYY-MM-DD>-<short-slug>.md`, update the index below,
> and refresh the **Latest checkpoint** pointer in `ROADMAP.md`. See
> [`AGENTS.md`](../../AGENTS.md) §7.6.
