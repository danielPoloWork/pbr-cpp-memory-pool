- **Library state on `master`** — All four spec §5 C functions carry real bodies in [`memory_pool.cpp`](../../../../src/main/cpp/it/d4np/memorypool/memory_pool.cpp) (no more M1 stubs). `memory_pool_create` allocates the contiguous backing via `::operator new(size, std::align_val_t{alignof(std::max_align_t)})`, enforces the ADR-0009 §2/§3 preconditions (`block_size ≥ sizeof(void*)`, `block_size % alignof(std::max_align_t) == 0`, `block_count > 0`, `block_size * block_count` overflow guard) returning `NULL` on any violation, and initialises the implicit free list in ascending address order using `std::memcpy` for strict-aliasing safety. `memory_pool_destroy` releases the backing via the matching aligned `::operator delete` and is a defined no-op on `NULL`. `memory_pool_alloc` / `memory_pool_free` are O(1) head-pop / head-push against the implicit free list; `memory_pool_free` additionally runs an O(1) range + alignment check (using `std::uintptr_t` arithmetic to avoid `[expr.rel]/4` unspecified behaviour) against the pool's backing extents and silently no-ops on foreign / out-of-range / misaligned pointers. C++ side: [`Pool`](../../../../src/main/cpp/it/d4np/memorypool/memory_pool.hpp) is a move-only RAII owner with `sizeof(Pool) == sizeof(void*)` and a single `memory_pool_t* handle_` member; `static std::optional<Pool> Pool::make(block_size, block_count)` is the Factory Method; `class PoolBuilder` is the fluent Builder. CTest registers one binary (`pool_smoke`) carrying the full doctest suite that covers the spec §5 surface, every ADR-0009 precondition violation, exhaustion + re-allocation, null-input safety, the four foreign-pointer / out-of-range / misaligned scenarios from ADR-0012, the `Pool` RAII move semantics, and the Factory + Builder happy and failure paths.
